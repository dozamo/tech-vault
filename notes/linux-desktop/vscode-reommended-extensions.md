# VSCode recommended extensions

## Extensiones de scripts de Bash recomendadas para VS Code

- ***REF 1:*** [Recommended Bash Scripting Extensions for VS Code](https://bats-core.readthedocs.io/en/stable/index.html) 

- ***REF 2:*** [Recommended Bash Scripting Extensions for VS Code](https://medium.com/devops-and-sre-learning/recommended-bash-scripting-extensions-for-vs-code-67c62a132978)

  - *Shellman:* Shellman is a VS Code snippet extension for shell scripts. It provides a free ebook (PDF, epub, mobi) that contains scripting basics and snippets.
  - *ShellCheck:* ShellCheck is a shell script static analysis tool. By installing ShellCheck, you can avoid many beginner pitfalls.
  - *Shell Script Language Basics:* This extension is bundled with Visual Studio Code. It can be disabled but not uninstalled. It provides syntax highlighting and bracket matching in shell script files.
  - *shell-format:* Shell-format formats shell scripts, Dockerfiles, gitignore, dotenv, and more. Shell-format helps you with indentations, removing extra spaces, and alignment.
  - *Bash Debug:* This is the most popular Bash debugger. It provides launch.json, pause support, watch-debug, and conditional breakpoints.
  - *Indent-rainbow:* You can use Indent-rainbow for all programming languages. It makes indentation more readable by colorizing the indentation on each block of code.
  - *VSC-Essentials:* There are some essential extensions which I will recommend for anyone to have installed if working with shared code base repositories.
